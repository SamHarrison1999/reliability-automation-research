# Protocols

This directory contains versioned technical feasibility and experiment protocols and, separately, the human-participant protocol. A protocol must exist before its experiment is run. The Phase 2 fit-probe protocol is [`phase-2-fit-probe.md`](phase-2-fit-probe.md), with the local execution record in [`../fit-probe/phase-2-fit-probe-results.md`](../fit-probe/phase-2-fit-probe-results.md). It is technical feasibility work only. Participant work requires the relevant ethics approval before recruitment or data collection.
