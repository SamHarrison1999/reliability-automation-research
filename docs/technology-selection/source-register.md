# Phase 2 technology evidence register

**Access date:** 2026-08-08

These sources document candidate capabilities. They are not evidence that a candidate will meet the project's research requirements in practice.

| Candidate | Official source | Capability relevant to this phase |
|---|---|---|
| Docker Compose | [Docker Compose documentation](https://docs.docker.com/compose/) | Defines and runs multi-container applications from versioned configuration and supports lifecycle operations. |
| Kubernetes | [Kubernetes overview](https://kubernetes.io/docs/concepts/overview/) | Automates deployment, scaling and management of containerised applications; its control-plane behaviour must be treated as an experimental dependency. |
| OpenTelemetry | [What is OpenTelemetry?](https://opentelemetry.io/docs/what-is-opentelemetry/) | Provides APIs, libraries and collectors for telemetry such as traces, metrics and logs. |
| Prometheus | [Prometheus overview](https://prometheus.io/docs/introduction/overview/) | Stores and queries timestamped time-series measurements and supports alerting-oriented monitoring. |
| Chaos Mesh | [Chaos Mesh overview](https://chaos-mesh.org/docs/) | Provides Kubernetes-oriented fault simulation and declarative experiment workflows. |
| Chaos Mesh HTTP faults | [HTTPChaos documentation](https://chaos-mesh.org/docs/simulate-http-chaos-on-kubernetes/) | Documents abort, delay, replacement and patch-style HTTP fault scenarios. |
| Litmus | [Litmus chaos workflow](https://docs.litmuschaos.io/docs/3.5.0/concepts/chaos-workflow) | Describes composed Kubernetes chaos experiments and their execution steps. |
| GitHub Actions | [Workflow syntax and permissions](https://docs.github.com/actions/using-workflows/workflow-syntax-for-github-actions) | Provides repository automation and supports least-privilege workflow permissions. |

## Interpretation rule

The descriptions above are capability statements from primary documentation. The selection matrix must not be read as a claim that the tools are interchangeable or that a documented feature will provide valid measurements without the fit probe.
