# ADR 0025: Phase 8 application evidence boundary

- **Status:** Accepted
- **Date:** 2026-08-12

## Context

The application must communicate substantial preparation without turning
technical feasibility evidence, a protocol-ready human study or a seed
literature map into stronger empirical claims.

## Decision

Phase 8 distinguishes four states:

1. completed technical empirical evidence;
2. completed protocol/design work;
3. planned future empirical work; and
4. external institutional dependencies.

The full Phase 1 scoping review remains explicitly incomplete.

The 600-1000-word proposal may use individually verified literature while
describing literature-gap conclusions as preliminary until the full review is
completed.

## Consequences

The proposal can demonstrate unusual methodological preparation while remaining
accurate about:

- pilot scope;
- participant evidence;
- literature coverage;
- ethics status; and
- supervisor/institutional dependencies.
