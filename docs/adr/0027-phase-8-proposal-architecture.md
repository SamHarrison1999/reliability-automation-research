# ADR 0027: Phase 8 proposal architecture

- **Status:** Accepted
- **Date:** 2026-08-12

## Decision

The School-specific proposal will follow the current OU structure:

- Title;
- Background;
- Aim and Method;
- Relevance;
- Your suitability.

The main narrative targets approximately 850-950 words within the current
600-1000-word School requirement.

## Rationale

The proposal must answer earlier methodological feedback while remaining concise
enough for the School-specific limit.

Technical repository detail is included only where it establishes empirical
clarity or feasibility.

## Evidence rule

No claim is added solely because it sounds persuasive.

Every substantive statement must be:

- supported by literature;
- supported by completed project evidence; or
- clearly presented as proposed future work.
