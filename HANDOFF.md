# Literature-review handoff

Target branch: `research/complete-literature-review`

Apply this package at the repository root after switching to that branch. It
adds the operational search plan, full-text charting rules, a provisional
literature map, a PRISMA-flow ledger and a claim-provenance register.

This package deliberately does not fabricate database result counts,
full-text findings or inter-reviewer agreement. The existing seed records are
labelled as seed/abstract evidence until the named database searches and
full-text checks are actually completed and logged.
