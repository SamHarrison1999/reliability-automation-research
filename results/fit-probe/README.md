# Phase 2 fit-probe evidence

This directory contains synthetic technical-feasibility evidence generated by the versioned Phase 2 harness. It contains no participant data, real payment data or production data.

- `fit-probe-summary.json` records the run-level validation result.
- `raw/` contains inspectable JSON Lines event bundles and run metadata.

The local execution target is deliberately identified as `local-process-fit-probe`. Kubernetes was not executed because `kubectl` and a cluster were unavailable in the probe environment. The Kubernetes manifest remains under `infrastructure/kubernetes/` for a later target-environment execution.
